What the file must look like

{% raw %}{ "id": "year7_mathematics_2027", "name": "Mathematics - Entrance Examination into Year 7 / JSS 1", "level": "Year 7", "entry_group": "year7", "subject": "Mathematics", "duration_seconds": 3600, "questions": [ { "id": 1, "text": "What is 2 + 3?", "options": ["4", "5", "6", "7"], "answer": 1 }, { "id": 2, "text": "What is 10 - 4?", "options": ["4", "5", "6", "7"], "answer": 2 } ] }{% endraw %}
  • id names the bank. Use lower-case letters, digits, hyphens and underscores only (for example year7_maths_2027).
  • Every question needs its own id (a number), its text, a list of exactly 4 options (A to D), and an answer that is the position of the right option, counting from 0 (so 1 is the second option).
  • A bank may hold up to {{ limits.questions }} questions. duration_seconds is how long a candidate has, from 60 seconds to 6 hours; it is one hour if left out.
  • To use the bank as an entrance paper, say which subject it is (Mathematics, English or General Knowledge) and which entry class it is for ("entry_group": "year7" for Year 7/JSS 1, "year10" for Year 10/SSS 1). General Knowledge can be shared by both.
  • Pictures are not imported. You can add a picture to a question afterwards by editing it.
