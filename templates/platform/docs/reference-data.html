The whole schema, read from the SQLAlchemy models when the server starts. A school's database is built from the models/ package alone (create_all() creates missing tables, and a small column-diffing helper in app.py adds any column an older database lacks), so there are no migration files to keep in step with this. The platform registry has its own models in control_plane/models.py and its own database.

Conventions that hold everywhere: timestamps are ISO-8601 UTC text (never DateTime), yes/no flags are INTEGER 0/1, and marks are floats so a 40-question paper can be worth 2.5 a question. Rows also answer to row['column'], which older templates rely on.
