  • Plain text may use letters, digits and - _ . (and / in student numbers). Nothing else: no spaces.
  • A pattern needs {{ '{seq}' }} or a random part such as {{ '{random:4}' }}, or every code would be the same. It may have one {{ '{seq}' }} at most.
  • The running number goes on from the biggest number already used by a code that is the same in every other part. So it starts again each year if {{ '{year}' }} is in the pattern, each month with {{ '{month}' }}, for each class with {{ '{class}' }}, and never if none of them is.
  • {{ '{seq:4}' }} is exactly 4 digits: after 9999 it is refused with a message, so widen it to {{ '{seq:4-5}' }} before that happens.
  • A finished candidate code is 3 to 40 characters, starting with a letter or digit. A student number is 1 to 40.
  • The previews use the class JSS 1 and today's date.
