What the file must look like

{% raw %}{ "id": "sss1_general_knowledge_2027", "name": "General Knowledge - Entrance Examination into SSS 1", "level": "SSS 1", "entry_group": "year10", "subject": "General Knowledge", "duration_seconds": 3600, "questions": [ { "id": 1, "text": "In what year did Nigeria become independent?", "options": ["1914", "1957", "1960", "1963"], "answer": 2 }, { "id": 2, "text": "What is the SI unit of force?", "options": ["Joule", "Newton", "Watt", "Pascal"], "answer": 1, "department": "Science" }, { "id": 3, "text": "A business owned by one person is a", "options": ["partnership", "sole proprietorship", "public company", "co-operative"], "answer": 1, "department": "Commercial" }, { "id": 4, "text": "A poem of fourteen lines is a", "options": ["ballad", "limerick", "sonnet", "haiku"], "answer": 2, "department": "Art" } ] }{% endraw %}
  • id names the bank: lower-case letters, digits, hyphens and underscores only (for example year7_maths_2027).
  • Every question needs its own id (a number), its text, exactly 4 options (A to D), and an answer: the position of the right option, counting from 0 (so 1 is the second).
  • Up to {{ limits.questions }} questions. duration_seconds is the time allowed, from 60 seconds to 6 hours; one hour if left out.
  • To use it as an entrance paper, give its subject (Mathematics, English or General Knowledge) and its entry class ("entry_group": "year7" for Year 7/JSS 1, "year10" for Year 10/SSS 1). General Knowledge can be shared by both.
  • department is optional: tag a question "Science", "Art" or "Commercial" when it tests that senior secondary department ("Arts" and "Commerce" are read the same way). In an SSS paper, each candidate then gets an equal share of questions from every department, and the admissions waitlist suggests the department their answers fit best. Leave it out for a general question.
  • Pictures are not imported; add one to a question afterwards by editing it.
