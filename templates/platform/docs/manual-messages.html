Every message the portal shows when something cannot be done, grouped by where it appears. Search for a few exact words of the message (the box at the top), or use your browser's find (Ctrl+F). Where a message has a longer explanation elsewhere in the manual, the last column links to it. "…" stands for a name or a number the real message fills in.
