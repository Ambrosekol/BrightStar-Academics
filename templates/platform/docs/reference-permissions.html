A school administrator's power is a set of permissions, gathered into roles. There are {{ p.total }} permissions. Each URL in the admin areas is mapped to exactly one of them in ADMIN_ENDPOINT_PERMISSIONS (core/security.py); an endpoint with no entry only needs admin.access. On top of permissions, an account can be scoped to particular classes, subjects or banks (see The school portal).
