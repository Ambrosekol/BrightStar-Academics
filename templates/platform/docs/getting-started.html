What you need

RequirementNotes
Python 3.10 or newerDeveloped and tested on 3.13.
PostgreSQL 14 or newerRequired in development as well as production. There is no SQLite mode and never will be: a bug that only PostgreSQL reveals must be found on your laptop, not at a school. Tested on PostgreSQL 18.
A database role that may CREATE DATABASEEach school's database is created when the school is. Locally the postgres superuser is fine. On a managed provider with no database literally named postgres (Aiven's default is defaultdb, for instance), set BRIGHTSTARS_PG_MAINTENANCE_DB to whichever one is guaranteed to exist — see the {{ page('reference-config', 'configuration reference') }}.
Nothing elseNo message queue, cache server or build toolchain. The PostgreSQL driver installs from requirements.txt. (Drawing a candidate's result image needs Chrome or Chromium; that one feature only.)

Install

git clone <the repository>
cd Academics

python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
copy .env.example .env         # Windows
# cp .env.example .env         # macOS / Linux

Configure

Open .env. Four values matter to get running; .env.example documents every other one, and the {{ page('reference-config', 'configuration reference') }} lists them all.

VariableWhat to put
BRIGHTSTARS_PLATFORM_DBYour PostgreSQL URL, for example postgresql+psycopg://postgres:yourpassword@localhost:5432/brightstars_platform.
BRIGHTSTARS_SECRETA real random secret: python -c "import secrets; print(secrets.token_hex(32))"
BRIGHTSTARS_PLATFORM_HOSTSplatform.localhost for development.
BRIGHTSTARS_PORTAL_DOMAINlocalhost for development.

You do not create any database by hand. python -m control_plane init creates the registry, and every school's database is created with the school. Browsers resolve *.localhost to your own machine, so a school called demo is reachable at http://demo.localhost:5000 with no hosts-file editing. A school's uploads and question banks default to a local folder (BRIGHTSTARS_TENANTS_DIR); if your host's disk is not persistent, see BRIGHTSTARS_STORAGE_BACKEND in the {{ page('reference-config', 'configuration reference') }} for an S3-compatible alternative.

First run

python -m control_plane init                        # create the registry database
python -m control_plane create-platform-admin ops   # your own platform login (the password is prompted)
python app.py
  1. Open http://platform.localhost:5000/. It goes straight to the console's sign-in page. Sign in as ops.
  2. The first platform admin you create is the super admin. Open Team in the rail to see it, and Docs, which is this documentation.
  3. Choose Create a school. Give it a name, a code (for example demo; it is permanent), a logo if you have one, and tick the option to start with the standard question banks. Enter a first administrator username so you get a one-time password.
  4. Open http://demo.localhost:5000/ and sign in with that administrator. You are now inside a school. Every screen you see there belongs to demo and to nobody else.
  5. To act as a platform operator inside a school without knowing its password, use Enter school on the school's page in the console. That mints a one-time ticket; see {{ page('platform-console', 'The platform console') }}.

Plain http://localhost:5000/ belongs to no school and no console, so it shows an "address not found" page. In development that page prints the console's address and the shape of a school's, which is usually what you were looking for.

Things to try while you are here

  • Create two schools and sign in to each in a different browser profile. Notice that nothing you do in one appears in the other. That is the point of the platform.
  • In a school, create a class, a subject and a student. Hand the student's one-time password to a second browser and sign in as them.
  • Open a school's Branding page, change the two colours, and watch every page change. See {{ page('branding-numbering', 'Identity and numbering') }}.
  • Register an entrance candidate and take a practice paper from /entrance-practice, which needs no sign-in.

Check that your setup is healthy

python tests/current/run_current.py

This is the fast contract suite. Run it after any change. It needs no database except that one check compares the models against the first registered school. The end-to-end scripts in tests/verification/ create throwaway databases, drop them afterwards, and never touch real data; see {{ page('testing', 'Testing') }}.

If something does not work

SymptomUsually
"Could not reach PostgreSQL to create the platform registry"The URL in BRIGHTSTARS_PLATFORM_DB is wrong, the server is not running, or the role may not create databases. If the underlying error says a database called postgres does not exist, your provider does not ship one under that name (Aiven's default is defaultdb) — set BRIGHTSTARS_PG_MAINTENANCE_DB to whichever one is guaranteed to exist.
A page that says "Address not found"You used localhost or an IP address. Use platform.localhost for the console and <code>.localhost for a school. The address chooses the school.
You are signed out every time you restartBy design: a restart signs everyone out (except people in the middle of an exam). See {{ page('operations', 'Operating it') }}.
Startup refuses with a message about the secretIn production the secret must be at least 32 characters.
Email or SMS does not sendNothing is configured yet. A school sets up its own under Email & SMS, or the deployment has a shared account. See {{ page('families', 'Students, parents and messages') }}.
