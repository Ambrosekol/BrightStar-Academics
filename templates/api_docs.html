Signing in: a key

The School Admin creates a key under Settings, API & webhooks, choosing the areas it may read. Send it with every call:

curl -H "Authorization: Bearer bsa_xxxxxxxxxxxx_xxxxxxxx…" {{ base }}/students

Keep the key secret, on a server, never in a web page or an app people can download. Every call is over HTTPS to the school's own address.

Answers, pages and errors

Every answer is JSON. A list is {"data": [...], "next_after": 123}, ordered by id. Ask for the next page with ?after=123 until next_after is null. ?limit= sets how many per page (1 to {{ max_limit }}, {{ default_limit }} by default). Amounts are in naira ("currency": "NGN"); times are ISO 8601, in UTC.

An error is {"error": {"code": "...", "message": "..."}} with the status: 401 no valid key, 403 the key may not read that area, 404 not found, 400 a filter is wrong, and 429 more than {{ rate }} calls a minute with one key (wait for Retry-After seconds).

A notice carries ids, not names or contact details: read anything more through the API. Answer with any 2xx within 8 seconds; anything else (or no answer) is tried again, up to five times. An address that keeps failing is switched off, and the School Admin sees why. The same id may arrive twice; treat a repeat as already handled.

Checking a notice really came from the school

Every notice has BrightStars-Signature: t=<unix seconds>,v1=<hex>. v1 is the HMAC-SHA256, with the address's signing secret (shown once, when it was added), of t, a full stop, and the raw body. Check it, and refuse a t more than five minutes old:

import hashlib, hmac, time

def is_genuine(secret, header, body):          # body: the raw bytes received
    parts = dict(p.split("=", 1) for p in header.split(","))
    if abs(time.time() - int(parts["t"])) > 300:
        return False
    expected = hmac.new(secret.encode(), parts["t"].encode() + b"." + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts["v1"])
