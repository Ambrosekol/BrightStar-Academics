Export all the school's data

One ZIP file with a spreadsheet for every kind of record the school keeps (students, parents, staff, classes, results, attendance, fees, payments, messages and the rest) and every uploaded file (photographs, signatures, attachments). Open the spreadsheets in Excel, keep the file as a backup, or take it to another system.

Left out: passwords and other sign-in secrets, and the school's stored keys for email, SMS and Paystack. It is prepared in the background (a large school takes a few minutes), kept for {{ keep_days }} days, then removed. It holds every family's personal data: keep it safe.
