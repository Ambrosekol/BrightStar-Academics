Environment variables

Read lazily, on each use ({{ file('control_plane/config.py') }}), so a test can set them after importing. Loaded from .env at start; a real environment variable already set outside .env always wins. .env.example documents every one with its reasoning, and so does the Settings page in the console itself, with a risk level, when to change it, what it affects and what breaks if it's wrong for each one ({{ file('control_plane/settings_registry.py') }}, {{ file('control_plane/settings_console.py') }}) — Low and Medium risk are editable by anyone with Settings access, High and Critical need the highly-trusted tier, and each one is written to .env directly, the same file this table is drawn from.

VariableDefaultPurpose
BRIGHTSTARS_PLATFORM_DBnone (required)PostgreSQL URL of the registry. No default, because a wrong guess would silently create an empty registry.
BRIGHTSTARS_PLATFORM_HOSTSplatform.localhostComma-separated hostnames (no ports) that serve the console, /marketing and /docs.
BRIGHTSTARS_PORTAL_DOMAINlocalhostThe domain schools' portal addresses are issued under.
BRIGHTSTARS_TENANTS_DIRtenantsWhere each school's data/, uploads/ and numbering.json live, when BRIGHTSTARS_STORAGE_BACKEND is local.
BRIGHTSTARS_STORAGE_BACKENDlocallocal (a folder on disk, above) or s3 (an S3-compatible object store — {{ file('core/object_store.py') }}). See the BRIGHTSTARS_S3_* rows below.
BRIGHTSTARS_S3_BUCKETrequired if s3The bucket a school's files are stored in.
BRIGHTSTARS_S3_ACCESS_KEY_ID, _SECRET_ACCESS_KEYrequired if s3Credentials for the bucket above. Store them as secrets.
BRIGHTSTARS_S3_ENDPOINT_URLunset (real AWS S3)Set for an S3-compatible provider that is not AWS: Cloudflare R2, Backblaze B2, DigitalOcean Spaces, MinIO.
BRIGHTSTARS_S3_REGIONautoThe bucket's region. Some S3-compatible providers ignore this and expect auto.
BRIGHTSTARS_S3_PREFIXnoneAn optional prefix every school's files are namespaced under, so one bucket can be shared with other uses.
BRIGHTSTARS_UPLOAD_CACHE_BYTES67108864 (64 MB)Bytes of uploaded-file content each worker keeps in memory ({{ file('core/storage.py') }}), so a second request for the same file — by any visitor — skips the bucket. Least-recently-used eviction, no expiry: an upload's path never changes what it holds. 0 disables it.
BRIGHTSTARS_PASSWORD_CHECK_CACHE_SECONDS30 (this deployment's example file sets 60)How long each worker remembers a signed-in person's password fingerprint before reading it from the database again ({{ file('core/session_guard.py') }}). A password change ends the person's other sign-ins within this time. A copy that disagrees with the session is re-read before anyone is signed out, so a stale copy never ends a fresh sign-in. 0 reads the database on every signed-in request.
BRIGHTSTARS_ADMIN_CACHE_SECONDS15How long each worker keeps a school administrator's account, permissions and scopes after reading them ({{ file('core/security.py') }}). A school's own changes clear them on the worker that handled the change; other workers catch up within this time. 0 reads them on every request.
BRIGHTSTARS_BADGE_CACHE_SECONDS10How long the counts on every admin page (unread notifications, open controls, unallocated payments) are kept per worker ({{ file('core/short_cache.py') }}). A change made on a worker clears its counts at once. 0 counts on every page.
BRIGHTSTARS_BRANDING_CACHE_SECONDS10How long a school's computed branding (name, colours, logo, contact details) is kept per worker. Saving branding clears it on the worker that saved it. 0 disables.
BRIGHTSTARS_SCHOOL_ENGINE_IDLE_SECONDS600How long a school's database connections may sit unused before they are closed; the next request rebuilds them ({{ file('control_plane/routing.py') }}). This keeps idle schools from holding connections on the database server. 0 keeps them open.
BRIGHTSTARS_DB_POOL_SIZE, BRIGHTSTARS_DB_MAX_OVERFLOW2, 3The connection pool each school's database gets in each worker. Raise them only when PostgreSQL's max_connections has room for schools × pool × workers.
BRIGHTSTARS_REGISTRY_POOL_SIZE, BRIGHTSTARS_REGISTRY_MAX_OVERFLOW10, 20The larger pool of the one shared registry engine, which nearly every request asks.
BRIGHTSTARS_PG_DUMPfound automaticallyThe pg_dump program a school export runs ({{ file('control_plane/provisioning.py') }}). Found on the PATH, then in the newest PostgreSQL install under Program Files (Windows) or /usr/lib/postgresql (Linux). It must be the same major version as the server, or newer.
BRIGHTSTARS_SECRETrandom per startSession-signing secret. Blank signs everyone out on every restart. In production must be at least 32 characters or the app will not start.
BRIGHTSTARS_ENVdevelopmentproduction makes cookies Secure, adds HSTS and enforces the secret's length.
PORT5000Port of the built-in server (python app.py).
BRIGHTSTARS_SCHOOL_DB_TEMPLATEbeside the registryWhere new schools' databases go: a URL with {slug} (the code) and/or {db} (the full name).
BRIGHTSTARS_PG_MAINTENANCE_DBpostgresWhich database CREATE DATABASE connects to when a school's (or the registry's) own database does not exist yet. Set this on a managed provider that does not ship one called postgres (Aiven's default is defaultdb, for instance). Only matters the first time — an already-existing database is used directly.
BRIGHTSTARS_REGISTRY_CACHE_SECONDS10How long a hostname lookup is cached per worker; bounds how fast a suspension takes effect. 0 disables.
BRIGHTSTARS_TRUSTED_PROXIES0How many reverse proxies are in front (0 to 5). See {{ page('deployment', 'Deployment') }}.
BRIGHTSTARS_MAX_UPLOAD_BYTES5242880Largest single image.
BRIGHTSTARS_MAX_REQUEST_BYTES8388608Largest request. Must be at least the upload limit.
BRIGHTSTARS_SMTP_HOST, _PORT, _USER, _PASSWORD, _FROM, _STARTTLS, _SSLunsetThe platform's shared mail account, the fallback for schools with none of their own. Blank host disables it.
BRIGHTSTARS_WHATSAPP_TOKEN, _PHONE_NUMBER_ID, _GRAPH_VERSIONunsetThe shared WhatsApp Business (Cloud API) account, likewise a fallback.
BRIGHTSTARS_DELIVERY_KEYderived from the secretKey that schools' saved mail and WhatsApp credentials are encrypted under. Set it early and never change it.
BRIGHTSTARS_CHROMEauto-detectedChrome or Chromium program, for candidates' result images.
BRIGHTSTARS_CONTACT_EMAILunsetWhere the public /marketing page's buttons write to.

Application settings worth knowing

KeyMeaning
app.config['BACKGROUND_INLINE']Run background notification work in the calling thread. Used by the tests; never set in production.
SQLALCHEMY_DATABASE_URIPoints at the registry, only because Flask-SQLAlchemy insists on a default bind. School data is never read through it.

CommandWhen you use it
initOnce per deployment, to create the registry.
create-platform-admin USER [--super]The first admin (automatically the super admin), and any later platform admin created from a terminal.
create-tenant CODE "Name"Scripted school creation. Options include --domain, --admin-username, --db-url, --no-starter-banks.
listEvery school, its addresses and database.
upgrade [CODE]Deploy step: brings schema(s) up to date and (with no code) records a new launch.
new-launchSign everyone out (except exam sitters) without restarting.
add-domain / remove-domainA school's own domain. The portal address can never be removed.
suspend / activateTake a school offline, or bring it back.
drop-retired-tables [CODE] [--yes]Show, or drop, leftovers of a removed feature.
sweep-jobs [CODE]Give every stuck background job another try, for a cron/systemd timer.
create-db-role CODE [--rotate]A PostgreSQL role owning exactly one school's database.
set-db-url CODE URLPoint a school at a different connection string.
rotate-delivery-key OLD NEW [CODE]Move every school's saved secrets to a new BRIGHTSTARS_DELIVERY_KEY before it is changed. See {{ page('recommendations', 'Recommendations') }}'s Hardening section.
export-tenant CODE [--output DIR]A school's whole database plus its own files, in one folder — what a school leaving is owed.
delete-tenant CODE [--output DIR]Permanently remove a school — its database, its files, and its place in the registry — after exporting it first. Cannot be undone; the export is the way back.
force-delete-tenant CODEThe same permanent removal, with no export taken first. For a school already exported, or one that was never real to begin with.

Every command above except init and create-platform-admin creating the super admin is also on the console's Settings page, under Terminal actions — see {{ page('platform-console', 'The platform console') }}.
