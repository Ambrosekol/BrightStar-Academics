Rotate the delivery key

Every school's own SMTP password, WhatsApp token and Paystack secret key is encrypted under this one key. Changing the environment variable directly would make all of them unreadable at once — this moves every school's secrets to the new key first, and only then lets you set the variable.

  1. Move every school's secrets from the current key to the new one
  2. Confirm every school shows 0 skipped
  3. Set BRIGHTSTARS_DELIVERY_KEY to the new key (restart required afterwards)
